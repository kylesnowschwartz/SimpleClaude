Copy this file to ~/.config/human-writing/personal-voice.md and fill it in.
That copy is yours; plugin updates never touch it.

Two rules keep this file useful:

1. Record only where you differ from the human-writing skill. Never restate
   its rules; they already apply.
2. Keep it short. A few precise lines beat a page of description. Delete any
   section you don't use.

Porting an existing voice document: read the human-writing SKILL.md and its
format references first, then classify each item in the source document:

1. The base skill already says it: drop it.
2. It contradicts a rule in Banned forms or Core voice: add a Rules to relax
   row naming that rule. Keep the part of the rule that still applies in the
   Replacement column.
3. It concerns one format: put it under that Per-format heading.
4. Otherwise it goes under General voice or Vocabulary, compressed.

Carry over a few writing samples verbatim. A ported file should be far
shorter than its source; if it isn't, it's restating the base skill.
-->
